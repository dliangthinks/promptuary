Promptuary Privacy Policy

Last updated: May 28, 2026

Overview

Promptuary is a local Model Context Protocol (MCP) server that runs entirely on your device. It reads and writes prompt template files (markdown) on your local filesystem and exposes them to MCP clients such as Claude Desktop.

Data Collection

Promptuary does not collect, transmit, or share any personal data. It does not make outbound network requests to any author-controlled service, has no analytics, and has no telemetry.

Data Usage and Storage

All prompt content stays on your device under the directory you choose (by default server/prompts/). Promptuary reads and writes only to that directory. Any data sent to an MCP client (e.g. Claude Desktop) is governed by that client's privacy policy, not this one.

Third-Party Sharing

None. Promptuary does not share data with third parties.

Data Retention

Prompt files persist on your local filesystem until you delete them. There is no server-side retention because there is no server other than the one running locally.

Browser Viewer

When enabled, Promptuary binds an HTTP server to localhost:9090 so you can manage prompts in a browser tab on the same machine. The server accepts connections only from localhost.
